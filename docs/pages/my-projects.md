# My projects (`/tiles`)

Everything you've made, in one place: tiles in this browser, in Pigxel cloud, and in Google Drive.

**Who can open it:** signed-in people.

## Features

### Browsing

- ✅ Projects from this browser and from Pigxel cloud in one grid, with thumbnails, names and where each is kept.
- ✅ Search by project name.
- ✅ Filters: All, Projects, Folders.
- 🔨 Filters **Shared** and **Favourite**: shown, with "This section is coming soon".
- ✅ Cloud projects load more as you scroll.
- ✅ "New project" card opens [New tile](new-tile.md).
- ✅ Empty states: "Nothing here yet", "Nothing matches your search", "This folder is empty".

### Folders

- ✅ Create, rename and delete folders.
- ✅ Move a project into a folder, or remove it from one ("Move to folder…").
- ✅ Open a folder (`?folder=`) to see only its projects.
- ✅ Folders hold Pigxel cloud projects; projects kept only in this browser stay at the top level.

### Project actions

- ✅ Open in the [Editor](editor.md) (reuses the existing draft when the project is already open).
- 🔨 Rename: only inside the editor today, not from this page.
- ✅ Delete a cloud project (with confirmation; only your own).
- ✅ Remove a browser-only or Drive project from this browser (the Drive file itself stays).
