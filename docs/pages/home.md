# Home (`/home`)

The signed-in starting point: pick up recent work or start something new.

**Who can open it:** signed-in people.

## Features

### Start creating

- ✅ **Blank canvas**: opens [New tile](new-tile.md).
- 🔨 **Generate with AI**: card shown as "Soon".
- 🔨 **Sprite animation**: card shown as "Soon".
- 🔨 **Tileset**: card shown as "Soon".

### Recent projects

- ✅ Up to four most recent projects, from this browser and Pigxel cloud, with thumbnails.
- ✅ Opens the right project; empty state leads to creating one.

### Learn and get inspired

- ✅ Tutorials section linking to [Tutorials](tutorials.md).
- 🔨 Popular templates: preview pictures marked "Soon"; they don't open anything yet.
