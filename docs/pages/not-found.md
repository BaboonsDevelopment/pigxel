# Page not found

Shown for any unknown URL, and for things that don't exist (an unknown artist or tutorial).

**Who can see it:** everyone.

## Features

- ✅ Public header, the Pigxel mascot, a large "404" and "This page wandered off".
- ✅ "Go to Pigxel" for guests or "Go to Home" when signed in, plus "Explore art".
- ✅ Returns a real 404 status for unknown URLs; hidden from search engines.
- ✅ Works on phones (no sideways scrolling).

## Planned and open

- ❓ A matching "Something went wrong" page with "Try again" for unexpected errors (the app has none yet, so crashes show Next's plain error page).
