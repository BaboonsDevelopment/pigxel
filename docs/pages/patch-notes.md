# Patch notes (`/patch-notes`)

What's new in each release.

**Who can open it:** signed-in people. The sidebar announces the newest release.

## Features

- ✅ One release per page, newest by default; pick another version (`?v=`); unknown versions show the newest.
- ✅ Release poster with version, date and "Latest" badge.
- ✅ Numbered chapters of changes (for example "Make your mark", "Bring it to life", "Find your colours").
- ✅ Link to start creating.
