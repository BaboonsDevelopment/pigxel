# Tool icon sources

Drop SVGs for the editor's drawing tools here, named after the tool folder in
`src/features/editor/tools/` (e.g. `pen.svg`, `bucket.svg`, `ellipse-marquee.svg`).

These are sources only. Each one is converted into that tool's `icon.tsx`:
16×16 viewBox, `fill="currentColor"`, `shapeRendering="crispEdges"`.
